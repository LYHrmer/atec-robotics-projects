**`task_b/brake_wheel_hold.py`** (~200 lines incl. docstrings)
- `BrakeWheelHold(dt=.02, kp=2., kd=.25, max_speed=.6, slew=2.)`; constructor validates `dt/kp/max_speed/slew` finite `> 0`, `kd` finite `>= 0`.
- `engage(q4)`: strict `(4,)` finite check, stores `.copy()`, `active=True`, `last_command=0`; a repeat `engage` while active validates the input then returns without re-anchoring.
- `release()`: clears anchor/active/last_command/debug; `update` on an inactive instance returns `0.0`.
- `update(q4, qdot4)`: per-wheel `e_i = atan2(sin(anchor_i - q_i), cos(anchor_i - q_i))`, `raw = kp*mean(e) - kd*mean(qdot)`, clipped to `±max_speed`, then `last += clip(desired-last, ±slew*dt)`; returns one physical rad/s target shared by all four wheels, same sign, no sides, no normalization, no world pose / GT / reward / camera / Isaac reads.
- Input guard rejects nested shapes (`(4,1)`, `(2,2)`), wrong length, NaN/Inf.
- `debug`: `wrapped_errors`, `mean_error`, `mean_qdot`, `raw_desired`, `command_rad_s`, `saturated`, `active` — all JSON-serializable. `describe()` reports params, physical units, inputs, the unused-signal list, that normalization belongs to `evaluate.py`, and that the module is experimental with no scored result claimed.
