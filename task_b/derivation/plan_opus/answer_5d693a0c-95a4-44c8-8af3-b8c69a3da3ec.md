## Behavior changes

**1. L>0 arm reach now identical to the passed P1 path** (`_reach`, `first_reach.py:364-427`)
- Removed the strict `REACH_VISUAL_HOLD` / `reach_visual_confirmation_lost` branch and the `lowering_m>0` hard stop `reach_base_not_stationary`. Detection state is diagnostic at every amplitude; no re-IK, no retarget, no deadline refresh.
- A component >.12 m from the localized point is now `reach_unassociated_component` at every amplitude (`reach_target_moved_beyond_12cm` is gone), so another object can never replace the one goal.
- The soft-settle (`_reach_settle`, unchanged .06/.12 thresholds, .2 s quiet, 2 s episode, 3 s total) and the drift budgets (.03 m / .05 rad / .05 rad) now cover all amplitudes; a settle freezes alpha and `arm_command`, and its time still counts.

**2. Lowering admission gate** (`_lowering`, `first_reach.py:469-527`)
- Requires a continuous .5 s window: actual arm error <.04 rad, arm |qdot|max <.05, public plane speed <.01, linvel <.06, omega <.12, tilt ≤.10, and not inside a rate settle. Leg stillness uses per-joint max−min of public leg q over that same .5 s window <.02 rad (not per-tick leg qdot). Leg/arm indices come from `observation_joint_names` (`leg_obs_ids`, `arm_obs_ids`, `obs[12+…]` positions, `obs[36+…]` rates).
- The wait clock starts at the first at-goal tick; ≥3 s without a window → `lower_quiet_window_not_formed`. A settle clears the accumulating window (`_reach_settle`). Authorization is latched once, copies `lower_reference_q0`, and no image/missing detection can re-arm it or re-copy q0.

**3. Descent and hold** — alpha rises ≤ dt/3 per step to the fixed CLI L, only while the actual arm is at goal and no settle runs; same arm q_goal and wheel anchor; `state` stays `REACH` (no new state, wheel hold untouched). `alpha≥1` → `LOWER_HOLD` ≥2 s → `reach_lowering_hold_complete`. Response checks: `increment_error>.06` for .2 s → `lower_joint_increment_error_exceeded`; beta <.15 one second after alpha≥.5 → `lower_reference_no_joint_progress`; beta is `None` when the delta norm is zero (L=0 never divides). Deadlines: original arm deadline unchanged, `+6 s` only after authorization (`_reach_deadline_s`, also used by the settle path), plus a 6 s cap from the authorization step → `lower_window_expired`. Every stop latches the current alpha (never zeroed, never raised).
