Interface as contracted: `StationaryTargetGate(dt=.02, sensor_period=.1)`, `reset(step)`, `update(step, quiet, point_body=None, source=None, frame_token=None)`, every return carrying `ready` / `target_body` / `confirmations` / `last_fresh_step` / `age_s` / `reason` / `freshness_basis` plus diagnostics (`step`, `source`, `quiet_s`, `settled`, `sample_steps`, `params`, `scope`, `claims`).

Behavior implemented:
- quiet must run continuously for `quiet_required_s` (0.2 s) **plus** one full `sensor_period` before any point is accepted; points arriving earlier return `pre_settle_point_discarded`. A fresh `reset` can never be ready on the first call.
- ready needs `min_confirmations` (2) same-source samples spaced `>= sensor_period` in control time, within `match_tol_m` (0.04 m); a larger gap clears evidence and restarts (`spatial_jump_restart`) instead of averaging.
- same `frame_token` from the same source returns `repeated_frame_token` and never counts; a *different* token that arrives sooner than one sensor period returns `sample_too_soon` and still does not count.
- with no token, `freshness_basis` is `sensor_period_elapsed_assumption`; no pixel-change requirement anywhere.
- `point_body=None` is an ordinary tick: it neither counts nor refreshes `last_fresh_step`, and it preserves an existing confirmation (`confirmed_hold`) until age exceeds `stale_s` (0.5 s), at which point ready drops and confirmation must be rebuilt.
- `quiet=False` clears evidence, quiet timer, source and token immediately; a source change rebuilds two same-camera samples.
- non-finite / wrong-shape / non-numeric points, missing or blank source, negative or backwards step raise `ValueError`; a repeated step returns the record unchanged without counting.
- `_as_point` copies into a tuple and `target_body` is a new list each call, so no caller array aliases internal state.
