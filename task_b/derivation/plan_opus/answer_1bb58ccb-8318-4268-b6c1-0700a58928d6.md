## `task_b/first_reach.py`

- **New state** (`__init__`): `reach_settle_start`, `reach_settle_calls`, `reach_settle_quiet_calls`, `reach_settle_episodes`, `reach_settle_cause`. None of them reset during a reach.
- **`_public_motion(obs)`** (new): records the actual public linear vector/norm, angular vector/norm and the vertical-free tangent speed plus the unchanged thresholds into debug, and returns them for the guards.
- **`_reach_settle(q, motion, violation)`** (new): entered only for `not reach_only and lowering_m == 0.` when `linear_norm >= .06 or angular_norm >= .12` (same thresholds). Freezes `arm_command` and `lowering_alpha` (returns `_action()` before the slew), keeps `state == 'REACH'`, sets `reach_subphase='SETTLE_AFTER_MOTION'` and a settle `state_reason`. Every settle tick — violating or recovery-quiet — increments the episode and accumulated clocks; only the quiet window resets on a new violation. Order per tick: total reach deadline → episode `>= 2s` → `reach_settle_timeout`, accumulated `>= 3s` → `reach_settle_budget_exceeded`, then `.2s` continuous quiet → resume the original goal (`reach_progress_anchor = None` re-anchors, `reach_subphase='RESUME_FIXED_GOAL'`). While settling it pins `reach_progress_anchor` to the current error and clears `reach_at_goal_start`.
- **`_reach` ordering**: `_public_motion` → immediate `reach_base_not_stationary` for `lowering_m > 0.` only → `_base_budget_exit` (so the .03 m/.05 yaw/.05 gravity budgets integrate on every call, settle included) → unchanged vision/diagnostic block and detector behavior → P1 settle → unchanged age/deadline, progress, q-tether and .30 slew.
- **Completion**: for zero-lowering P1, `error < .04` now also requires arm qdot max `< .05`, tangent speed `< .01` and the original v/ω norms under threshold, continuously for 2 s; any failure or settle clears `reach_at_goal_start`. `lowering_m > 0.` keeps its exact previous path. `describe()` gained a `reach_settle_contract` block (thresholds, budgets, episode/settled totals, explicit "a pause is not a stillness claim").
