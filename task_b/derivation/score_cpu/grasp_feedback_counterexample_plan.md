# Grasp 01 公共关节偏差与下一候选 CPU 检查

仅本地准备；不修改生产、不启动 GPU、不上传。用户最新禁上传窗口延至 2026-09-14 10:20:22 UTC。

实测数据来自 `task_b_score/plan_p4_grasp_seed42_01`；详细数值见同目录 `grasp01_joint_bias_review.json`。telemetry 的 q/qdot/物体状态是动作前，不能把同索引状态称为该动作的结果。正常 stop record 是最后实际动作之后的下一次决策，未执行停止决策的新动作。

LIFT 最后 1 秒 q2 的 `command - actual` 均值为 -0.060698 rad，实际 q2 变化范围只有 0.001159 rad；q3 均值误差只有 +0.002872 rad。末状态 q2 指令 3.040008、实测约 3.100239。与近稳态负载/接触阻挡偏差一致；没有关节力矩及双指接触力证据，无法进一步把负载与碰撞分开。

夹爪末 1 秒 q7≈+0.026258 m、q8≈-0.018222 m，宽 44.195–44.665 mm；指令保持 [-0.015,+0.015] m，实际并未落到闭止挡，且处于原硬限以内。存在机械阻碍的解释合理，但宽度本身不证明夹住目标瓶，也不证明摩擦承载。

下一候选约定：固定原实测 lift goal，外层仅用公共实际 q，`compensation = clip(1.0 * (goal - actual), -.08, .08)`；候选命令投影到原每轴 0.10 rad/s、actual±0.10 rad、静态硬限三者的交集，空交停止。实际 q 误差、FK 上移、qdot、窗口、暂停、deadline 和物理环境不改。

若旧 run 的平均偏差在改命令后保持恒定，代数平衡及原 FK 预测 gain 0 时实际误差 0.060698 rad、上移 6.343 mm；gain 1 时实际误差 0.030349 rad、上移 17.060 mm。此假设下 q2 补偿约 -0.030349 rad，命令约 3.009658。相对 15 mm 门槛只有约 2.06 mm 余量，不能当作真实抬升结果。

独立 CPU 反例准备：

1. 保留现有 42 项审计，原 FirstReach 全前缀、闭爪参数和全部停止边界不变。新补偿可以改变 command，断言应固定测量目标而非错误要求 command 等于目标。
2. 合成一阶位置响应，q2 加 +0.0607 rad 偏差，使用已命名映射的公共 q/qdot；允许原硬限约束。检查反馈方向向负、绝对补偿≤0.08，goal 在全程不变，并检查所有下发命令的速率、tether 和硬限。即使合成偏差模型达到实际 q/FK 门槛也仅说明逻辑可执行。
3. 冻结实际关节：持续较大实际误差不能靠增长 compensation 或 command 到位授权 OBSERVE；仍在原 2 秒 active 无改善窗口停止。
4. 大于 cap 的偏差和错误方向偏差：补偿饱和不改变目标/物理限位，不能绕过 actual precision；不得解除原 rate/tether 交集停止条件。
5. 公共 q 轻微噪声、近目标误差交替符号：输出速率仍受限，补偿不能只靠 command 抵达/预测 FK 触发；实测 qdot≥0.05 或实测 FK 上移不足仍拒绝。
6. 暂停期间实际 q 变化：arm/finger 下发命令冻结、既有低姿态/轮 anchor 不变；恢复才重新计算受约束命令，预算不清零。无积分器时也不允许通过换目标实现隐式积累。
7. 固定 goal 接近静态硬限：compensated target 即使超硬限，最终命令必须留在三者交集内；若被限位后实际目标仍不可达，按原 deadline/无改善停止，不能将目标改成可达值。

真实验收仍由 root 的原任务 GPU run 和离线物体姿态审计完成。非空夹爪、命令补偿或 CPU 通过均不构成抓握/投递/通关证据。
