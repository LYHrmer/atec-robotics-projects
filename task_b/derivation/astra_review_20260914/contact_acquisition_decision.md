# 接触位置修正：下一次有界候选

2026-09-14，Astra ultra 方案；由根代理调用真实 Claude Opus，仅实现 `task_b/contact_grasp.py`。

采用 `FirstReach(lowering=.02)` 正常完成 → 实测确认张开 → q6 相对当次实测值旋转 +30° → 独立增加 .02 m 腿参考 → 原 force75 闭夹及小抬升。总参考下降 .04 m；不改变 FirstReach 的 .03 m API 上限，不声称实际下降量等于参考量。额外准备加原 probe 全局最多25秒，原本体漂移、倾角、暂停预算连续保留。具体实现合同为 `task_b_plan_opus/contact_grasp_prompt.md`。

选择依据：

- 原 force75 的末端上升54.408毫米，而同一物体实际姿态变换后的原始 mesh 最低点最高只增加0.864毫米，最终空夹。肩关节参考不足已经解除，不能继续只增加夹紧力。
- 新 contactdiag 运行直接读取原 PhysX 材料：机器人25个shape及10号瓶的静/动摩擦均为1，瓶质量 .5 kg。闭夹末 .5 s 双指均持续接触；对手指的法向力 Z 为 +5.75/+6.77 N，对瓶相反为向下。抬升非空期两指法向仰角26.7°/29.6°。该传感器只记录法向合力，不包含摩擦，不可将其当完整支撑力。
- 使用 force75 首次 PROBE_CLOSE（step2924）的实际 q、底盘及物体四元数重放原始 mesh。若在现有 .03 基线上直接转30°，31个角度样本有6个左指几何交叠；在静态腿几何中提高1厘米后，41个旋转样本零交叠，最窄原始mesh间隙约2.92毫米。此高度对应采用 .02 初始路径的候选依据，并非已经实测同一个 .02 终态。
- 转30°后下降到总参考 .04 的41个路径样本零交叠。终态左指首次接触面法向仰角约1.3–1.6°，较原25.5°接近竖直瓶壁；右侧属于多面交界，活跃面法向约−0.3至20.7°，不能声称两侧均完全接触直壁。

局限：上述几何使用离线真实物体位姿，只用于选定实验参数，绝不进入策略；原始凸包交叠不等于 PhysX cooked mesh 接触模型，也未包含 contact offset。相机与力诊断必须继续核验实际新路径是否触碰、推歪或滑脱。新的 FirstReach(.02) 前缀应与同参数冻结 FirstReach 逐步对照，不能声称与旧 .03 轨迹相同。

验收优先级：实际开放旋转和下降完成 → 新闭夹接触位与双指法向方向 → 同物体最低mesh点离地并与末端持续跟随至少1秒 → 才启动已准备的高举/越桶沿模块。近距离得分、关节到位、非空夹爪均不代替抓起或投递证据。

证据：`contact_force75_wrist_depth.json`、`contact_rotation_clearance_followup.json`、`task_b_score_cpu/grasp_force75_independent_mesh.json`、独立 contactdiag force 报告。保持当前禁止上传期限；本文件仅私有实验说明。
