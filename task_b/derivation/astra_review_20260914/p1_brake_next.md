## 采纳与暂缓

**推荐唯一主要变量：在 BRAKE→REACH 期间增加公开轮位置外环。** 保持 standoff=.50、compact、stance_hold、轮增益8、forward .05、IK、视角与下降0。加外环的目的，是用原动作接口提供有限的速度目标抵消回滚；这不是修改官方执行器。

不优先改变 standoff：它同时改变刹停触发位置与复测容许阈值，不能消除相对回退。单独提前多前进几厘米，可能让第一次复测通过，但 .02–.03 m/s 的回滚会在约 6.8 s 的臂运动里积累更多误差。降低转向/改变腿形/添加脉冲没有针对本次静止失败的直接因果证据。若原位置保持外环无法让公开位移和实测轮角稳定，再按本轮记录诊断，不同时调整这些参数。

## 给 Opus 的窄模块合同

只新增 `task_b/brake_wheel_hold.py` 和对应 CPU 审计文件。主代理负责动作映射和 FirstReach 接入，避免代码所有权冲突。

```python
hold = BrakeWheelHold(dt=.02, kp=2.0, kd=.25,
                      max_speed=.60, slew=2.0)
hold.engage(wheel_q_rad)       # 一次 BRAKE 入口，四轮按约定名称顺序
common_speed = hold.update(wheel_q_rad, wheel_qdot_rad_s)
# 返回 float 物理共同轮速 rad/s；hold.debug 提供误差/限幅/输出诊断。
hold.release()
```

计算每轮短角误差 `e_i=atan2(sin(q_anchor_i-q_i),cos(q_anchor_i-q_i))`，再取平均，输出共同轮速目标 `u=clip(2.0*mean(e)-.25*mean(qdot),-.60,.60)`，按每步≤`2.0*dt` rad/s 变化限速。本次第一段出现约 **12.5655 rad 的原始轮角包装跳变**，直接 `anchor-q` 会产生错误饱和；必须处理角度周期。此任务位移范围很小，短角误差没有多圈定位需求。

模块输出物理 rad/s，**不是既有策略归一化 action**。当前 wheel.scale=5、wheel_action_gain=8，集成到 gain 前时应除以 40，所以最大原策略轮 action 为 .015；经 gain 后 .12，与原近场微进物理目标 .60 rad/s 同级。不得再把 .60 当归一化 action 乘 gain。模块不能读奖励、接触力、世界位姿或物体根位置。

首次 BRAKE 的同一次 policy.act 返回后立即 engage，不等 gate 已静止才启动。BRAKE、REACH_READY、REACH、REACH_VISUAL_HOLD 使用同一 anchor，不因检测 tick 或 state 显示变化重置；重复 engage 不重锚。重新接近时 release，下次 BRAKE 重新锁；白名单以外全部 release，尤其 RECOVER_STANCE/TILT_STOP/STOPPED/done。初始 engage 的命令从0平滑启动，不能复用之前转向/前进命令。

主代理已选择在 evaluate 显式 `--brake_wheel_hold` 开关后组合，当前限 first_reach、零下降。读取现有公开 proprio 的轮 q/qdot 与控制器自身 state/done；在姿态/腿参考/保持的动作变换后、最终 drive×gain 前写入轮切片。更高优先级的姿态恢复或硬停止必须使 hold 失活，不允许位置保持覆盖停止指令。此组合不新增诊断观测作为策略输入。

静止视觉授权仍通过公开观测判断；建议把能宣称“静止”的证据补充为重力切平面速度<.01 m/s 连续 .2 s。它是与新增保持外环配套的验收条件，不用于让仍在回退的旧回合强行伸臂。若不修改现有 gate 条件，也必须在下一回合报告这个更严格指标是否满足，不得把原 .06 阈值通过本身写成位置保持成功。

CPU 验收限于有意义失效：前滚应给后向校正、后滚应给前向校正、±2π/±4π 包装不反向、不使用腿/臂索引、限幅/限速、重复 state 不重锁anchor、release 后输出零、动作映射只除/乘 gain 一次。旧 trace 可验证回滚时输出正确符号和包装连续性，**不能把对旧轨迹计算出控制量当作已模拟其动态效果**。
