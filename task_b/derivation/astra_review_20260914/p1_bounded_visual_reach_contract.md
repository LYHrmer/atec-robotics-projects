## 直接证据与决定

两张原始保存 PNG 均清楚显示目标，使用原 HSV 与 3×3 opening 原样回放：step2250 主黄色块 `[145,198,69,68]`、area3112、h/w=.985507；final 主块 `[153,212,68,69]`、area3063、h/w=1.014706。原 detector 要求 h/w≥1.15，这一形状条件在深度处理之前直接拒绝近圆的俯视瓶体。2340 的成功检测框为49×68，来自局部狭长分量；不能要求同一瓶子在视角变化时始终呈竖长形状。

2345 的目标中心仍投影在 `(172.61,236.77)`，光学深度 .6191 m，不是中后段几何出框。故当前修复不继续增加 FOV 例外，而明确采用“静止视觉定位后，一次有界关节反馈轨迹”。缺少某次启发式检测本身不证明目标移动。RGB 复放证据仅证明形状关口失败；缺少保存深度，不能宣称已复原所有后续深度/高度检查。完整 JSON 为同目录 `p1_hold_visual_shape_audit.json`。

## Opus 实现范围：仅三个文件

`task_b/first_reach.py`、`task_b/visual_approach.py`、`task_b/audit_first_reach.py`。不改 evaluate/轮保持/原环境，不开 GPU，不改搜索阶段的默认检测行为。

1. `detect_yellow_candidates` 新增 `locked_target_body=None`。默认 None 保留全部原搜索门槛；非 None 时仅略过 h/w∈[1.15,6] 检查，仍要求 area≥35、bbox高度≥10、原有效深度/点云/metric_height规则，并在得到三维点后只保留距 locked_target_body≤.12 m 的候选。锁定点需为3个有限数；该门控不用物体编号或真值。
2. `_detect` 仅在 `reach_q` 已由 stationary_gate 真实授权之后传入锁定点。初始搜索、微进、BRAKE 仍采用原检测器。跟踪结果只提供观测诊断/一致性检查，不重新求 IK，不更改已锁定的目标关节；空间门外候选记 unmatched，不能强认成原物体位移。
3. 对 `lowering_m==0` 且通过真实静止 gate 的 REACH，一次缺测、形状拒绝或预期出框都只更新诊断，不再进入 .5 s REACH_VISUAL_HOLD。继续执行同一 q_goal，保留 .30 rad/s、实测 q±.10 tether、原总时限、3 s 关节无进展、原公开 base速度/倾角/角速度停止条件。合成 reach_only 的诊断边界不变。lowering>0 不获得新豁免，本轮仍零下降。
4. REACH_READY 保存公开 gravity、平面位移零点和 yaw 积分零点；每步用 `v_plane=v-(v·up)up` 积分局部净平移，norm>.03 m 停止；`abs(integral(omega·up))>.05 rad` 停止；gravity方向相对入口改变>.05 rad 停止。它是受小角度约束的局部近似，用于限制计划动作期间底盘变化，禁止把含明显离散偏置的竖直速度积分当目标高度或驱动追分。积分不得在每个缺测/重新检测时清零。
5. 调试输出明确标记 `initial_visual_then_bounded_joint_feedback`、累计局部平移/yaw/重力变化、检测年龄与空间匹配状态。保留几何投影诊断，但不把它当“画面内一定能检测”的证明。统计总时长不可被新视觉或状态别名反复刷新，缺测许可只适用于本次同一个 gate 目标和 q_goal。
