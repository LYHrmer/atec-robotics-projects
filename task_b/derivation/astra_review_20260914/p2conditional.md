# P2 条件方案：静止伸臂后的固定腿参考缓降

2026-09-14，Astra 条件设计；只读检查本轮冻结的 FirstReachPolicy，未修改控制器、未运行 GPU。**本方案只有在 P1 实际完成真实视觉授权、伸臂到位和稳定保持，而独立诊断确认仅余少量厘米距离缺口时，才值得实施。当前没有此项放行证据。** 不因这里给出参数就立即追加运行。

## 五条建议

1. **把臂伸到位和缓降拆成两个授权阶段。** 当前 `_reach` 用 `lowering_m==0` 判断整个伸臂阶段可否使用预期出框许可，因此简单将 CLI lowering 从 0 改成 .01，会在实际 alpha 仍为 0 时取消已通过的 P1 路线。条件实现应按阶段区分：`ARM_REACH` 且 `alpha==0` 沿用 P1 的一次有界预期不可观测许可；达到臂误差≤.04 rad、臂 qdot<.05 rad/s、底盘与腿静止连续 .5 s 后，才评估独立 `LOWER_REFERENCE` 授权。臂达到目标不能自动开始下探。

2. **缓降采用事前限定的腿参考动作，不根据丢失视觉后的目标距离追加动作。** 仅沿用现有 `lower_delta * (L/.02)`；固定臂目标、轮为零，L 在新进程中依次为 .01/.02/.03 m，alpha 以最多 `dt/3` 增加，3 s 完成一轮，随后保持 2 s 并结束该次尝试。L 是参考几何设计值，不宣称实际下降了 L。目标锚点来自制动后的真实静止视觉；目标在两相机的确定几何范围外时可以执行这一已经限定的动作，但不重估物体根高度、不继续增大 L、不重新 IK 追分。新的有效检测应与当前位姿变化容许范围核对；意外出现明显目标移动则终止。若仍在预测视野内却丢失，维持 P1 的失效处理，不把所有缺测都豁免。

3. **用公开姿态和关节变化限制动作，阈值相对该次稳定起点。** 进入 LOWER 时保存 q_leg0、q_arm0、gravity0 和公开 twist 基线；只有起点 tilt≤.10 rad、腿 qdot 最大绝对值<.05 rad/s、臂误差≤.04 rad、线速度<.06 m/s、角速度<.12 rad/s 连续 .5 s 才授权。执行中任一条件满足就锁存停止：tilt>.12 rad；gravity 方向相对起点改变>.035 rad；积分 yaw 改变>.04 rad；角速度 norm>.12 rad/s 连续 .06 s；重力切平面速度>.04 m/s 连续 .10 s；积分平面位移相对起点>.02 m；臂误差>.06 rad 连续 .20 s；腿 qdot>.20 rad/s 连续 .10 s；`max(abs((q_leg-q_leg0)-alpha*lower_delta))>.06 rad` 连续 .20 s。原 .25 rad 硬停和官方终止仍有效。这些是保守起始候选，需要 P1 的实际静止噪声记录核对，不能为了通过而事后默默放宽。

4. **必须有限时退出，且停止不等于自动回升。** 动作时间上限为 4 s ramp + 2 s hold；alpha>=.5 后 1 s，若在 lower_delta 方向的实际关节投影 `beta=dot(q_leg-q_leg0, lower_delta)/dot(lower_delta,lower_delta)` 仍小于 .15，则记 `lower_joint_reference_no_progress`，不继续下降，也不直接增加 L。beta 仅检查关节是否响应，不能证明机身变低。任一停止条件锁存当下 alpha，保留已有 compact + stance_hold 支撑，禁止继续下降和轮驱，保存原因后结束回合；不在倾斜时突然把 alpha 清零。若以后需要平缓回升，另验证它，不能把冻结写成已经安全回升。

5. **只让独立有界模块管理 alpha，先 CPU 审计，再由本轮 P1 证据决定是否集成。** 建议 `BoundedReferenceLowering.start(anchor)` 和 `update(public_state)` 返回 `phase, alpha, done, stop_reason, diagnostics`。anchor 包含当前公开腿/臂角、gravity、twist 基线、原 lower_delta、固定 L、实际视觉授权/预期不可观测的状态证明；public_state 仅有 q/qdot、base twist、gravity，以及调用方给出的观测有效性。模块不接收 world root、对象 root、contact、reward 或 scoring_events；不改动作 schema/执行器/奖励。CPU 重点检查 L>0 但 alpha=0 的 ARM_REACH 不受旧配置级门槛误拦；未到位/未静止不能 start；重复 start 不能重开许可；每个失效分支锁存 alpha、不跳回 0；噪声基线/平面与竖直分解正确；L=.01/.02/.03 的 alpha 上限、速度和 6 s 总时限不可越界。最终仍由独立诊断验算实际运动与原始奖励。

## 公开 twist 的使用注意

不能把公开线速度逐步全量积分后，直接作为几厘米精度的目标 z 或实际机身下降估计。旧 camera_seed42_02 最后 200 步，公开速度均值约 `[-.001915,-.000201,.023334]` m/s，而同 4 s 区间 root 世界 z 变化约 `-.000032` m；方向对齐重力后，平面速度最大值仅 .000340 m/s。这个差异是本次离线诊断事实，足以否决“直接积分完整 twist 就能准确跟踪几厘米竖直位置”的未经验证前提。

P2 控制因此优先用：`up=-gravity/norm(gravity)`、`v_plane=v-dot(v,up)*up`；用公开角速度积分的相对旋转，把 v_plane 转到进入 LOWER 的局部参考坐标再积分平面位移。无需世界位姿。进入前 .5 s 的 `mean(dot(v,up))` 可以作为竖直速度偏置，`dot(v,up)-baseline` 仅作异常哨兵，例如绝对值>.04 m/s 持续 .10 s 就停；不得用它驱动“还差多少厘米”或宣称真实下探量。此偏置也不能用于抵消真正的平面移动。

P2 视野计算不能永久沿用未修正的 body_target：基座下降和倾斜会改变静止物体的机体系位置。最小做法是只接受事前锚定目标、有限 L 与姿态/位移边界，不把近似目标更新用于闭环距离追踪；若重投影用于判定意外缺测，必须考虑 `L≤.03 m` 加上允许平面/角度变化的目标位置包络，而不是把名义 alpha*L 视为实测平移。只在整个容许位置包络均不处于两相机可观测范围时，才称为有确定几何依据的不可观测；否则使用保守缺测处理或先补充视觉定位。

## 本轮 P1 尚需观察的一种条件性阻断

冻结代码在采样时未检出目标且中心点仍投影在画面内，会立即保持臂命令，.5 s 后退出。部分瓶体/黄色区域可能先被裁切或因形状条件拒检，而中心点还在画面内；保持命令后也就无法继续运动到中心点出框区。这是代码结构上的可能死锁，**尚无本轮轨迹证据，不能声称必定发生**。若 P1 停在 REACH_VISUAL_HOLD，只需先核对当时 `reach_camera_projection`、候选拒绝原因与实际 RGB，判断是意外丢失还是预计的部分裁切，不直接放宽所有失视觉门槛。

P2 不属于本轮冻结实现。本轮最终究竟推进 P2、修视觉、修 IK 或修关节跟踪，必须由 P1 的真实状态与独立距离审查决定。
