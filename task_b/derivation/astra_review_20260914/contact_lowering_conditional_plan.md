# 仅在增强预紧仍滑脱时执行的接触高度候选

采用 `GraspProbePolicy(lowering_m=.03)`，原样传入冻结的 `FirstReachPolicy`；保留 preload=.025、paired lift=.20、q2反馈和全部门槛。没有必须增加 postnormal 下探阶段的理由。先等当前回合真实瓶底/跟随审计，不提前实施。

最小实现只涉及 wrapper：允许既有 .02 和新 .03 两个降低量，默认 .02 不变；将配置值原样交给 FirstReach，完成其既有3 s参考下降、2 s保持后才闭夹。同步元数据和错误说明，准确报告允许值及本次 lowering。运行脚本使用 `--reach_lowering .03`。原 FirstReach、动作、物理、奖励和终止均不改。

几何依据来自 `contact_lowering_geometry.py/.json`，使用已完成 feedback01 闭夹入口的实测腿/臂、basequat、objectquat：

- 当前参考降低 .02，实际基座 z=.517228 m；将总参考改为 .03，固定轮位置拟合给出基座 z=.507253 m、倾角 .07098 rad。最小腿硬限余量 .59996 rad，四轮刚性拟合最大残差 .112 mm。
- 基座保守可视包围盒最低 z=.37072 m，大腿最低 z=.22738 m；这些不是精确碰撞保证。原 fall 使用 base z<0，非法接触阈值1 N；规划不利用该阈值主动碰撞，也不向策略输入真实高度/接触力。
- 指端轴末点 z由 .20084 变 .19092 m，瓶在指端深度区间中的 Y 跨度由45.37增至63.60 mm；有希望由较窄的颈部接触移到肩部，但不能声称已进入直壁主体。
- 最大70 mm张开下，新增10 mm位置的两指理想原mesh凸包均未与固定瓶相交。新增20 mm时已有一指相交，新增30 mm时两指均相交；故暂不做总 .04/.05参考，也不越过 FirstReach 的 .03合法参数上限。

验收：wrapper 前缀必须等于**同参数 FirstReach(lowering=.03)**，不能声称与旧 .02实际轨迹相同；默认 .02保持原行为。CPU检查 .02/.03入参传递、其它值拒绝、元数据一致、原normal/failure转移不变。新完整环境进程中先核验合法得分/无原失败，再审计实际下探、闭夹位置和同一瓶的实际quat/mesh离地及至少1 s跟随。即使策略正常进入OBSERVE，也不自动判定物理抓取成功。

保持 FirstReach 既有授权和下降响应检查：实测臂误差<.04、臂速度<.05，公开平面速度<.01/线速度范数<.06/角速度范数<.12/倾角≤.10，以及原腿窗口；下降跟踪误差>.06持续.2 s停止、原进展/6 s期限不变。wrapper沿用同轮锚、降低腿参考、夹空、暂停、漂移和10 s probe总期限。所有GT几何仅用于本文件离线诊断。
