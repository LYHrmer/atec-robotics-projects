## 4. 关键技术发现（这部分对制定新方案最重要）

### 4.1 负载下的 1.67 Hz 结构模态（已解决）

- 用记录的原驱动常数 K=80、D=4，取 J≈0.727 kg·m²（臂+.5 kg 负载）：
  **固有频率 = 1.670 Hz，阻尼比 ζ = 0.262**，与实测完全一致；
  由它推出的重力下垂 0.170009 / 0.082038 rad 与合同静态界一致。
- 现象：振荡**在标量路径走完（α=1）那一刻才出现**，且**永不衰减**。
- 修复：比例增益 4 → 0.9~1.25、阻尼 .05 → .15~.20 + 实测速度低通。
  实测臂速度 **.2721 → .0832 rad/s**。
- **注意**：我一度把修复归因于「重力前馈」，**这是错的**——复核发现
  `arm_command - reference` 实测≈0（闭夹姿态下 q2 正好压在原关节上限
  3.1400065/3.1399998），前馈是空操作。真正起作用的是降增益+加阻尼，
  以及后面的积分微调。代码与日志已更正。

### 4.2 公开 qdot 的 Nyquist 采样伪迹（已做测量修正，**需要外部复核判断**）

原始采样：
```
qdot: -0.1511  +0.1529  -0.1513  +0.1526  -0.1515  +0.1526   ← 每个采样变号
q   :  1.645002 1.645806 1.644993 1.645794 1.644958 1.645756  ← 摆幅仅 .0008 rad
```
- 相邻位置差 .0008 rad = **.041 rad/s**，而报告的 qdot 是 **.152 rad/s**，
  两者**相差 3.7 倍互相矛盾**。符号逐采样翻转 = 恰好 Nyquist（50 Hz 下的 25 Hz）。
- 同一 25 Hz 分量在**腿和轮**上同样存在 → 求解器/传感伪迹，非机械臂动力学。
- **增益/阻尼对它完全无效**：把增益从 1.25 降到 .9、阻尼从 .15 升到 .20，
  侧摆段的数值纹丝不动（.1512 → .1523）。
- 采取的修正：速度门改用**相邻两采样均值**（Nyquist 分量精确抵消，
  1.67 Hz 处增益 .9945）。**阈值 .12 rad/s、.5 s 窗口、.002 rad 位置窗口全部未改**，
  位置窗口仍是真实运动的约束；debug 同时输出原始与修正值。
- **这是本次唯一的判断性改动，请外部重点复核是否合理。** 反对意见：这毕竟是改了
  验收门所测的信号。支持意见：位置与速度两个测量互相矛盾时必有一错，位置自洽
  （.0008 rad / .5 s ⇒ 平均速度 ≤.0016 rad/s）。

### 4.3 到位判定曾是主要瓶颈（已解决）

七次负载运行里前六次**位置早就到位**（误差 .0226–.0328 rad < .04 门），
卡的是 `.12 rad/s` 速度门 + 完整 26 采样静稳窗口。最终解法组合：
降增益 + 阻尼 + 实测速度低通 + 慢积分微调（补静差）+ Nyquist 修正。
