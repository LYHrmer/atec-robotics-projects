后续优先保留首分配置作为对照，每个实验改变一个有明确依据的因素。零下降与 P2 的区别、真实关节与命令、媒体时间与仿真时间继续分别报告。单个种子只能证明该回合发生过什么；需要事先指定的多个新回合后，才能报告相应条件下的成功比例。

物理抓取阶段需要重新验证夹持点与手指接触几何；当前固定目标伸臂只是接近路线。图像不可观测期间的有界运动许可不会自动扩展成搬运期的抓持确认，也不把本次 0.74 秒保持推定为长期稳定。

## 持续保留的控制边界

- 原机器人、场景、物体、执行器、动作接口、奖励与终止条件保持不变。配置仍只采用已记录的单环境、设备及 Fabric 选项和官方安全动作初始化。
- 策略只接收公开本体观测、原相机 RGB-D 和静态结构信息。根位姿、物体位姿、接触力及奖励只作评测/离线诊断，不能反馈选目标、下探幅度或下一动作。
- 伸臂前必须取得停稳后的新定位；锁定后保持同一个关节目标，并保留关节速度/跟踪误差、姿态、公开速度、累计机身运动和时间预算。缺检与不匹配候选只能作诊断，不能授权下探。
- 下探幅度在进程启动前固定，准入来自实际关节误差、关节运动与公开底盘状态。短暂超速用有限时长暂停处理，仍保留原阈值和总预算；不把参考完成当成真实下降。
- 每次使用新进程、新输出目录，单 GPU 串行运行。首个官方终止立即停止；评测器可以在明确观察窗口结束时提前收尾，并如实标记未完成的控制阶段。
