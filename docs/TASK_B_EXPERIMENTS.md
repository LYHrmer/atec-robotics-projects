**当前 Task B 仍为 0 分，未完成物理抓取或投递。** 已在这台电脑上实际运行官方 `ATEC-TaskB-B2wPiper`，验证四轮低速前行、定位主要接触失败，并把 Claude Opus 编写的稳定控制模块与公开 RGB-D 接近控制进行了对照。稳定模块延长了本次存活；参考站姿迭代消除了正常姿态的持续误限速，但实际转向仍弱，未完成目标接近。

本轮保存 **13 条实际运行记录**，其中 1 条是明确标记的观测映射集成失败，另外 12 条进入相应实验比较。启动失败和不完整序列化回合另外保留在本机，不与有效方法记录混算。

## 本次运行条件

固定 seed 42、原官方起点与 18 物体布局、单环境；50 Hz 控制、200 Hz 物理；RTX 5060 Laptop 8 GB、Isaac Sim 4.5 / Isaac Lab 2.3.2。机器人、地形、物体、碰撞、执行器、奖励与终止条件均使用本机官方配置，未修改原工程源码。每次新进程，首次终止即停止，包含初始 100 步静止期。

策略输入是公开本体观测及原相机 RGB-D、静态机器人几何。根位姿、物体位姿和接触力只单独记录供诊断。相机兼容读取沿用 Task A 的只读递归变换，不给移动相机写入覆盖父节点的世界变换。

## 已完成的基础与视觉对照

每行只有一次记录，不能估计成功率。位移与偏航变化采用第 100 步和最后一条**步前**状态之差；初始落地和滑移不算轮驱进展。不同截断时长不能直接排名任务效率。

所有分数都是原始环境返回奖励除以 `step_dt` 后累计，两项奖励各自保存。`grasped_objects` 只检测夹爪进入 0.20 m 范围；即使取得这一分也不能称为抓起。所有 18 个物体同时入圈才触发原始成功条件。

稳定模块的问题已定位：正常静止姿态的 `sin(tilt)≈0.0633` 略高于初版门限 0.06，持续触发限速，把差速压到约 0.088。Claude 收到反馈后实现了单独的参考站姿候选：第 100 步从末 20 帧稳定观测冻结参考，并保留独立绝对倾角检查。参考版本已真实运行，解决了这项误触发，但仍没有形成足够转向，不能把倍率较大的微小转角变化宣传成任务性能提升。[参考版本 CPU 检查](../results/task_b_neutral_profile_cpu_audit.json) · [实现与原始预测](../task_b/NEUTRAL_REFERENCE_DESIGN.md)

## 视觉与机械臂已验证到哪一步

移动 Piper 的 FK/IK 使用 B2w 上实际安装的静态变换 `(0.2,0,0.1)`，与 Task E 固定桌面坐标分开。CPU 随机姿态对实际 USD 的位置误差最大约 `7.98e-8 m`；运动学一致不保证碰撞自由、负载稳定或真实抓持。[运动学审计](../results/task_b_arm_kinematics_cpu_audit.json)

视觉控制在公开腕部图像中用颜色、形状、有效深度与两帧确认找黄色高物体，尚不是通用语义识别。固定臂姿下的近场视野不足；已实现原头部 RGB-D 接续，合成双视图及默认旧模式等价性检查通过，但尚无真实回合靠近后跨相机持续跟踪的成功证据。[相机接续 CPU 检查](../results/task_b_visual_handoff_cpu_audit.json)四个抽样时刻的离线核对中，反投影点与对应物体初始根位置的 XY 距离约 3.4–4.0 cm；反投影的是可见表面点，根位置也不是分割真值，不能把该距离包装成严格定位精度。[离线投影核对](../results/task_b_visual_projection_runtime_audit.json)

目前没有可用的稳定下蹲、接近后抓起、越过桶沿和松爪入圈证据。原桶壁约 0.5 m，连底座后顶部约 z=0.55 m；运输时还需考虑瓶体在夹持点下方的长度，不能沿地面推过墙。

## 实现与失败记录如何保留

- 初次旧入口选错 5.1 Kit 配置，未进入步进；改为本机 4.5 后才完成短测。启动失败不是控制策略的零分回合。
- 初次新入口误把连续轮的非有限软位置限位视作错误，已改为只要求位置控制关节具有有效限位。
- 深蹲首轮终止记录曾出现 Tensor 序列化错误；随后以新目录重跑，取得实际复位前接触数据。
- `visual_approach_seed42_01` 是集成失败：读取了 `task.cfg` 中尚未解析的关节下标，导致 FK 用错关节顺序。已改用 ObservationManager 的实际解析副本，并逐步核对一致性。该录像在本机保留，原结果公开，**不作为视觉方法的有效基线**。
- 原样 `result.json`、元数据、加载源码哈希、逐步遥测和无损压缩的 `trace.jsonl.gz` 见各运行目录；`public_package.json` 保存源文件与解压后哈希。结果中的文件名保留原运行语义，公开 trace 仅做 gzip 压缩。

稳定器的倒立判定、异常重力、float32 溢出和失目标停车语义已完成独立 CPU 检查；正常姿态序列在边界修复前后逐位一致。[稳定器审计](../results/task_b_stability_cpu_audit.json) · [动作/复位审计](../results/task_b_bootstrap_cpu_audit.json)

压缩 trace、逐步遥测和各源结果哈希集中在 [Task B Release](https://github.com/LYHrmer/atec-robotics-projects/releases/tag/task-b-bootstrap-20260910)。按用户要求，本次 Task B 得分前录像只保留在本机；Release 不含视频。全部既有 Task A/E 录像继续保留。
