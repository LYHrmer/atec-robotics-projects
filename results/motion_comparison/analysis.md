两次都达到 **18/18**。原始评测核对为同 seed 42、同初始摆放、相同动作配置与物理参数。本目录只公开机器人关节遥测和精简结果，不包含物体真实位姿。

| --- | ---: | ---: | ---: |

| 六臂关节总行程 | 44.47216 rad | 42.56863 rad | −4.28% |

| 腕 joint6 差分加速度 RMS | 3.78990 rad/s² | 3.80358 rad/s² | +0.36% |

## 提速来自哪里

- `CLOSE`、`VERIFY_LIFT`、`OPEN`、`VERIFY_PLACE` 合计缩短 **6.30 s**。候选在夹爪状态或实际分数满足条件后提前通过原有确认门槛，原有失败检查仍执行。
- 糖盒 `RETRACT` 从 **3.92 s** 降至 **1.00 s**，但 `HOME` 从 **1.36 s** 增至 **2.70 s**。合并看两段是 **5.28 → 3.70 s**，实际净节省 **1.58 s（29.92%）**。
- 另有 **0.18 s** 来自香蕉放置阶段更早触发满分终止；不能把它独立解释成规划器提升。

## 糖盒回撤：避免无必要的反向转腕

| 阶段/指标 | 基线 | 快版 |
| --- | ---: | ---: |
| RETRACT 腕 joint6 行程 | 2.598303 rad | 0.000487 rad |
| HOME 腕 joint6 行程 | 0.656306 rad | 1.871230 rad |
| RETRACT+HOME 腕 joint6 行程 | 3.254609 rad | 1.871717 rad |
| RETRACT+HOME 六臂关节总行程 | 6.277477 rad | 4.506365 rad |
| RETRACT+HOME 六臂关节加速度 RMS | 3.623770 rad/s² | 3.226819 rad/s² |

回撤时保持姿态，确实消除了篮上方的大幅转腕；回到 home 时仍需转回初始姿态。合并两段的腕行程下降 **42.49%**，比只宣传 RETRACT 的 99.98% 降幅更能反映完整动作。

## 加速度的取舍

全程差分加速度 RMS **上升 4.36%**，不能声称所有平顺性指标都改善。只看糖盒 RETRACT，六臂关节 RMS 从 3.57970 升至 4.40885 rad/s²（+23.16%），虽然该阶段的腕 joint6 RMS 从 5.38514 降至 0.26313 rad/s²。

同时，RMS 与整段速度 P95 都会受等待时长影响。仅合并 `PREGRASP/DESCEND/LIFT/TRANSPORT/PLACE/RETRACT/HOME` 等运动阶段，六臂关节 RMS 为 **3.75252 → 3.71889 rad/s²**，约下降 **0.90%**；糖盒回撤和 home 合并后也下降。应同时报告全程指标与阶段构成，不把缩短等待带来的统计变化直接等同于更猛烈或更柔和的运动。

这些是 **50 Hz 本地采样**。加速度由实际 qvel 差分得到，阶段边界按后一个样本归属；不是连续时间 jerk、接触冲击或全路径无碰撞保证。当前只有该初态的对照，其他种子的验证另行记录。

两次原始采集的录像设置不同（基线无录像，快版有录像），不据此主张墙钟计算速度提升。公开精简结果不保存墙钟和本机路径；本报告的“更快”指仿真任务完成时间。

## 复现统计

在仓库根目录、具备 NumPy 的 Python 环境运行：

```bash
python3 tools/task_e/compare_motion.py \
  results/baseline42_motion results/fast42_motion \
  --relative-to . --output-dir results/motion_comparison
```

该命令重算 `comparison.json` 和 `comparison.md`，不启动仿真。`analysis.json` 的联合阶段行程/时间为分组相加；联合 RMS 以各分组 `adjacent_intervals` 加权均方后开根号。原始遥测与精简结果分别位于 [基线](../baseline42_motion/result.json) 和 [快版](../fast42_motion/result.json) 目录。`implementation` 保留被测试入口的 SHA256，运行目录用仓库相对路径表示。
